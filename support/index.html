BookOrbit iOS

Support

How can we help?

Get help

Ask a question or report a reproducible problem by opening a support issue.

Include the BookOrbit app version, device software version, server version, and steps to reproduce the problem. Do not post passwords, access tokens, or private server addresses.

Connection problems

Confirm that your BookOrbit server address opens on the same device. If someone else operates the server, contact that server administrator about account access, certificates, or availability.

Premium purchases

Open Settings > BookOrbit Premium and select Restore Purchases. The App Store must use the Apple Account that made the purchase.

Manage a yearly subscription in Apple subscription settings. Apple handles billing, cancellations, and refunds.

Privacy and security

Read the Privacy Policy. For app privacy or security questions, open a support issue. Do not include secrets or private details.
