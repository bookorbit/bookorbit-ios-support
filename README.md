# BookOrbit iOS support

Report bugs, request features, and follow BookOrbit releases in the [issue tracker](https://github.com/bookorbit/bookorbit-ios-support/issues).

## Current release

[BookOrbit 1.8.0 (30)](https://github.com/bookorbit/bookorbit-ios-support/milestone/11) is available on the App Store as of November 7, 2026.

This release brings the app to German, French, Spanish, Dutch, Italian, and Simplified Chinese. It adds Guided View for comics, Story Recap, Constellations, Find Your Page, cover and shelf scanning, Spotlight and Siri search, Year in Review, a redrawn Reading Insights, Bedtime mode for audiobooks, and many more reader controls. It also fixes stale covers, Read Along going silent at chapter boundaries, and iPad and iPhone Duo layouts. Year in Review, Find Your Page, and cover and shelf scanning require BookOrbit server 3.7.0 or later.

See [release notes and history](RELEASES.md) or [all release milestones](https://github.com/bookorbit/bookorbit-ios-support/milestones?state=all). The next version has not been scheduled.

## Status labels

| Label | Meaning |
| --- | --- |
| `planned` | Accepted and scheduled for a version |
| `in-progress` | Being investigated or built |
| `fixed` | A bug fix is complete in development |
| `implemented` | A feature or improvement is complete in development |
| `pending-release` | Completed work is waiting for the App Store version named by its milestone |
| `testflight` | The change is available in a TestFlight build |
| `released` | The change is available on the App Store |

Each release has a version milestone, such as `1.8.0`. Completed work remains open with `fixed` or `implemented` and `pending-release`. When it ships, the issue gets a comment naming the version and build, changes to `released`, and closes. Topic labels stay in place.

Support questions, workarounds and duplicates may close without being assigned to an app release. Requests without a scheduled version remain outside release milestones.
